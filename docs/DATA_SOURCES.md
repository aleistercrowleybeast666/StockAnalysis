# 数据来源与缺失策略（0.4.1）

程序按字段记录实际来源、请求标识、抓取时间、币种、状态、回退原因和字段级状态。第三张可见页展示本次覆盖率与来源成功数，逐公司明细保存在隐藏的 `数据来源` 页。

## 运行内健康探测

A/H 历史资金流分别最多探测 3 家高流动性样本。只有全部样本取得严格 22 日数据，主源才用于剩余公司；否则本次运行立即改用对应备源。这不是跨运行负缓存，下一次任务仍重新探测。

## 严格语义

- `-`：有证据证明数学或业务上不适用。
- 空白：请求、解析、换算或完整性验证失败。
- `0`：来源成功且确认结果为零。

ETNet 和 AASTOCKS 的港股大额成交解析器均已实现，但本次 2025 年公开列表不能证明完整年度，因此年度字段必须空白。TradeGo/AASTOCKS 能提供港股 5 日值，但公开的 20 日/5 日口径不能写入 22 日列。

## 无跨运行缓存

0.4.1 不创建或读取 SQLite、字段缓存、负缓存和原始响应目录。相同结果只在当前任务内复用。有限重试结束后会记录失败并尝试备源；不存在让后续全部公司跳过的跨公司熔断。
