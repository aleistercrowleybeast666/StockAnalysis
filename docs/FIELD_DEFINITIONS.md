# 字段定义与计算口径

两张主表固定为 A:AE 共 31 个业务列。第 3 行是分组表头，第 4 行是字段名，数据从第 5 行开始；筛选位于第 4 行，冻结窗格为 `H5`。

| 分组 | 列 | 字段 |
|---|---:|---|
| 公司信息与分类 | A:G | 证券代码、公司名称、板块（上市板块）、行业、概念、实际报告期、报表币种；概念主表最多 12 项，完整列表见隐藏明细页 |
| 营业收入 | H:J | 所选年度营业收入、同比、三年 CAGR |
| 毛利率 | K:M | 毛利率、同比变化、三年变化（后二者均为百分点） |
| 归母净利润 | N:Q | 归母净利润、归母净利率、同比、三年 CAGR |
| 经营活动现金流 | R:T | 净额、同比、三年 CAGR |
| 上市发行与市场交易 | U:AE | 最新总市值、上市日期、发行价、发行股数、发行时总市值、最新可得价格、市值增长率、大宗交易笔数/金额、5/22 个交易日资金净额 |

主表不显示字段状态、公司状态、`SUCCESS`、`PARTIAL` 等内部技术信息。状态和来源只保留在隐藏审计表中。

## 显示规则

- 金额在模型中以元保存，主表除以 `100,000,000` 显示为亿元；发行股数显示为亿股。
- `-` 只表示数学上或业务上不适用；抓取、解析、换算或验证失败显示空白。
- 真实零值必须显示 0，不得用空白或 `-` 冒充。只有来源成功且确实没有大宗交易时才显示 0 笔、0.00 亿元。
- 金融企业仍进入结果，但营业成本和普通工商企业毛利率口径不适用时，K:M 显示 `-`。
- 港股发行资料、大宗交易和资金流等可选字段取得失败时留空，不因此判定公司失败。

## 计算规则

- 营业收入同比：`本期 / 上期 - 1`；比较期缺失时留空，上期不为正时显示 `-`。
- 三年 CAGR：`(本期 / 三年前)^(1/3) - 1`；两端必须为正。
- 毛利率：`(营业收入 - 营业成本) / 营业收入`。
- 毛利率同比/三年变化：本期毛利率减去比较期毛利率，以百分点显示，不称 CAGR。
- 利润或现金流同比：`(本期 - 上期) / ABS(上期)`；允许负数，上期为 0 时不定义。
- 归母净利率：`归母净利润 / 营业收入`。
- 发行时总市值：只按 `发行价 × 发行后总股本` 计算，缺任一项即留空。
- 市值增长率：`最新总市值 / 发行时总市值 - 1`；发行时总市值必须大于 0。
- A 股“近一月资金净额”为最近 22 个有效交易日；港股为最近 20 个有效交易日。

主表由程序写入已校验的标准化数值，不依赖 Excel/WPS/LibreOffice 的公式缓存。

## 入选与排序

“总市值前 N 家”按最新总市值降序、证券代码稳定排序。缺市值者不参与 Top N；核心年度财务缺失者被跳过并由下一名补位。最终工作表可按最新总市值（默认）或分析年度营业收入排序。

## 隐藏审计表

- `历史数据`：当前/比较期原值、币种、行情日期和质量说明。
- `概念明细`：逐证券保存全部概念与主表展示文本，避免主表 12 项上限造成信息丢失。
- 第三张可见页 `数据来源说明`：面向用户的数据源矩阵、计算口径和空值语义。
- `数据来源`：字段组、实际来源、请求标识、抓取时间、币种、状态和回退主源。
- `异常记录`：只记录真正需要诊断的源错误或核心缺失；普通可选缺失不制造大量错误行。
- `运行信息`：版本、配置快照、成功/排除计数、请求性能、本次运行内复用，以及每个市场的识别、排名、候选、生成、核心财务跳过和退市过滤数量。
