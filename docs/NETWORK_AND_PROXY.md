# 网络、代理与重试（0.5.0）

- 默认网络模式为“国内数据源优先直连”：国内与 HKEX 公开来源先直连，传输失败时尝试系统代理；境外来源遵循系统代理环境。
- “全部直连”和“系统代理”保留在内部配置中用于排障，普通 GUI 不暴露端点、Token、并发或代理细节。
- 每个域名共享限速器，使用连接池、明确超时和有限退避重试。
- 不存在跨运行结果缓存、负缓存或健康状态。每次生成重新请求公开来源。
- 资金流在本次任务开头对少量高流动性证券做健康探测；稳定的主机级错误会让本次运行切换备源，避免对 Top100 重复同类失败。该状态不会保存到下一次运行。
- 大宗交易、资金流和发行资料按市场、证券和字段隔离；一个可选来源失败不会丢弃另一个市场已经取得的数据。
- 日志记录来源、功能端点、直连/代理、耗时、重试和回退原因，不记录访问令牌。
