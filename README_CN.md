# 股票分析表生成器

`StockAnalysis 0.5.0` 是一款本地 PySide6 桌面软件，用公开数据生成 A 股和港股年度分析 Excel。它用于个人数据整理与技术研究，不构成投资建议；重要数据仍应以交易所公告和公司原始财报为准。

## 使用方式

1. 选择完整财务年度。年份上限按系统时间自动更新为上一自然年，例如 2027 年会允许选择 2026 年。
2. 勾选 A 股和/或港股；两个市场默认均启用。
3. 每个市场可单独勾选“限制为总市值前 N 家”。未勾选时采集该市场全部公司，保存的 N 不参与本次范围计算。
4. “包含 ST 股票（仅 A 股）”默认勾选；取消后才排除名称含 ST 或 `*ST` 的 A 股。
5. 选择最终工作表按最新总市值（默认）或分析年度营业收入排序，然后选择输出目录并开始生成。

A 股和港股名额互不借用。例如两边都设为 Top100 时，目标是 100 + 100，不会均分总名额，也不会固定预取 120 家。只有入选证券缺少所选年度核心财务时，程序才继续向后补位。

## 更新方式、资金流模式和网络模式

- **更新方式**：旧的手工更新选项已经删除。每次生成都会重新访问公开来源，不读取或写入跨运行的行情、财务、负结果或原始响应缓存；只允许同一次任务内复用完全相同的批量响应和页面。
- **资金流模式**：无需手工选择。程序在本次运行内先做少量健康探测，再按市场自动回退。A 股分别计算最近 5/22 个有效交易日，港股分别计算最近 5/20 个有效交易日；其中一个窗口成功不会伪造另一个窗口。
- **网络模式**：默认“国内数据源优先直连”。程序先直连国内和 HKEX 等公开来源，稳定的传输错误才尝试系统代理；单一来源或单只证券失败会被隔离并尝试备源，不会让另一个市场已经取得的数据丢失。

## 成功、部分缺失、排除、失败和缓存

- **成功**：公司具备所选年度核心财务并写入主表；可选字段仍可能因公开来源缺失而留空。
- **部分缺失**：核心数据可用，但至少一个理论适用字段在主源和备源均未取得。
- **排除/跳过**：证券不在选择范围、不是目标普通股、已终止上市，或没有所选年度核心营业收入。Top N 会按真实缺口继续向后补位。
- **失败**：证券池/排名整体不可用、Excel 无法写入，或出现真正的程序错误。单个可选来源失败不会把整家公司误判为失败。
- **缓存**：没有跨运行缓存；旧版残留数据库和缓存目录不会被读取。本次运行内的去重、连接池和来源健康状态在任务结束后失效。

GUI 的“公司成功数”和字段覆盖率是两层判定。即使 200 家公司都成功进入主表，整列业务字段仍会触发发布门禁；详细来源和空白原因写在第三页、隐藏审计页和日志中。

## Excel 数据语义

前三张可见工作表固定为 `A股`、`港股`、`数据来源说明`，另有隐藏的历史、来源、异常和运行信息页。主表保持 28 个业务列；A 股最后一列是最近 22 个交易日，港股最后一列是最近 20 个交易日。

- `-`：数学或业务上明确不适用，例如金融企业的普通毛利率。
- 空白：字段理论上适用，但已实现的主源和备源仍未取得，或无法证明统计区间完整；港股发行资料也可能因发行时间过早、公开网站无记录而留空。
- 数值 `0`：来源成功并且确认结果确实为零。

发行时总市值只允许按“发行价 × 明确的发行后总股本”计算，不能用发行数量、募集金额或当前总股本代替。第三页同时列出静态来源链和本次运行逐字段覆盖率、实际成功来源及主要空白原因。

## 进度条

点击开始后立即显示不确定进度和“正在准备证券范围与数据源”。证券范围与任务规模确定后切换为单向、确定百分比；总进度按真实市场、公司任务和请求批次推进，不把扫描证券池固定算成前 30%，也不会在不同轮次重置。

最终 Top100+Top100 实测中，70% 出现在总墙钟耗时的 62.9% 处，最大普通跳变为 5 个百分点；完整结果见 `PROGRESS_VALIDATION_REPORT.md`。

## 日志与绿色目录

Windows onedir 的日志与 EXE、依赖目录处于同一父目录：

```text
StockAnalysis/
├─ StockAnalysis.exe
├─ _internal/
└─ logs/stock_analysis.log
```

macOS 冻结版日志位于 `.app` 同级：

```text
发布目录/
├─ StockAnalysis.app/
└─ logs/stock_analysis.log
```

构建 smoke 产生的日志不会打进正式 ZIP；用户首次运行时才创建 `logs`。

## 构建与发布

Windows 严格构建：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap_windows.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build_windows_onedir.ps1
```

macOS 不能由 Windows 交叉伪造。仓库通过 `.github/workflows/build-macos.yml` 在 `macos-15` arm64 和 `macos-15-intel` x86_64 runner 上分别构建原生 `.app`；也可以在真实 Mac 上运行：

```bash
./scripts/bootstrap_macos.sh
./scripts/build_macos_onedir.sh
```

发布产物、架构、测试和 SHA-256 以 `BUILD_REPORT_Windows.md`、`BUILD_REPORT_macOS.md` 及 `dist/` 内报告为准。数据源见 `DATA_SOURCE_REPORT.md`，测试见 `TEST_REPORT.md`，港股缺失边界见 `HK_ROOT_CAUSE_REPORT.md`。
