# 股票分析表生成器

`StockAnalysis 0.4.1` 是本地 PySide6 桌面工具，使用公开数据生成 A 股与港股年度分析 Excel。软件只用于个人数据整理与技术研究，不构成投资建议；最终仍应以交易所公告和公司原始财报为准。

## 当前交付状态

## GUI 使用

1. 选择完整财务年度。上限按系统时间自动取上一自然年；例如 2027 年会自动允许选择 2026 年。
2. 勾选 A 股和/或港股，两个市场默认均启用。
3. 每个市场可勾选“限制为总市值前 N 家”；未勾选时为“全部公司”，保存的 N 不参与本次范围计算。
4. “包含 ST 股票”默认勾选；取消后仅过滤 A 股 ST、`*ST` 公司。
5. 选择最终工作表按最新总市值（默认）或分析年度营业收入排序。
6. 选择输出目录并开始生成。

A 股与港股名额完全独立。A 股 Top100 与港股 Top100 的目标是 100 + 100，不存在总名额均分或跨市场补足。Top N 先按真实最新总市值排名；核心年度财务缺失时才继续向后补位，直到补足或证券池耗尽。

## 更新方式、资金流模式与网络模式

- **更新方式**：GUI 已删除这个旧选项。0.4.1 不读写跨运行 SQLite、字段缓存、负缓存或原始响应缓存；每次点击开始都会重新访问来源，只在当前任务内复用完全相同的请求。
- **资金流模式**：GUI 已删除手工开关。程序自动尝试 A/H 两市；先对历史主源做最多 3 家健康探测，未全部取得严格 22 日就切换备源。能证明 5 日但不能证明 22 日时，只填写 5 日，22 日保持空白。
- **网络模式**：普通 GUI 不暴露技术开关。默认“国内数据源优先直连”，国内/HKEX 来源先直连，传输失败时尝试系统代理；内部仍保留全部直连和系统代理配置用于排障。

## 进度、成功、排除、失败与缓存

点击开始后进度条立即出现。证券范围未知时是单向不确定动画，且不占固定百分比；数量确定后按行情、财务、发行、大宗交易、资金流、计算和导出的计划工作量，从 0% 单向走到 100%，跨市场和批次不重置。

- **成功**：核心年度财务可用并进入主表；不代表所有可选字段均有值。
- **部分缺失**：核心数据可用，但某些理论适用的分析字段未取得。
- **排除/跳过**：非目标普通股、终止上市，或没有所选年度核心营业收入；Top N 会继续向后补位。
- **失败**：证券池/排名完全不可用、Excel 无法写入，或发生真正程序错误。
- **缓存**：没有跨运行缓存；旧版本遗留缓存不会被读取。当前运行内的相同批量响应可复用，但程序退出后不保留。

GUI 摘要与字段覆盖率是两层判定。即使显示“200 家成功”，若有整列业务字段为空，发布门禁仍会失败；详细原因写入日志和工作簿审计页。

## Excel 与数据语义

前三张可见工作表固定为 `A股`、`港股`、`数据来源说明`，另有隐藏的历史、来源、异常和运行信息页。主表固定 28 个业务列。

- `-`：数学上或业务上确实不适用，例如金融企业普通毛利率。
- 空白：已尝试来源但抓取、解析或完整性验证失败。
- 数值 `0`：来源成功，并确认所选口径结果为零。

发行时总市值只按“发行价 × 明确的发行后总股本”计算；缺任一项即留空。第三页同时展示静态来源链、本次实际来源成功数、覆盖率和主要空白原因。

## Windows

严格构建命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap_windows.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build_win.ps1
```

当前测试预览位于 `dist/win`。必须整体解压 `StockAnalysis_Windows_onedir.zip`，不能只复制 EXE。版本、哈希和门禁状态见 `BUILD_REPORT_Windows.md`。

## macOS

Windows 不能交叉生成可信 `.app`。将同一精确提交放入 Git 仓库后，可手工触发 `.github/workflows/build-macos.yml`，或在目标架构真实 Mac 上执行：

```bash
./scripts/bootstrap_macos.sh
./scripts/build_mac.sh
```

当前没有 `dist/mac`，详见 `BUILD_REPORT_macOS.md` 和 `docs/MACOS_HANDOFF.md`。

数据源与当前覆盖率见 `DATA_SOURCE_REPORT.md`，测试见 `TEST_REPORT.md`，进度实测见 `PROGRESS_VALIDATION_REPORT.md`。
